# 配当管理アプリ

iPhone向けの配当・分配金管理Webアプリです。サーバー不要で、GitHub Pagesにファイルを置くだけで動きます。

## 機能
- 銘柄管理（ETF・投資信託・国内株・海外株）：口座（特定口座・NISA成長枠・NISA積立枠。NISAは国内課税を免除）、保有数量／保有口数、平均取得価額（必須）、現在値（任意）、配当月と各月の金額（コピー機能つき）、税率（20.315%・海外28.28%・手動入力）
- 配当入力：月ごとに見込み額を自動計算。実際の受取額を税引後で記入
- 投資信託：普通分配（課税）と特別分配（元本払戻金・非課税）を分けて記入
- ホーム：月別の棒グラフ（特別分配を含む／含まないを切替）、銘柄別の円グラフ
- 分析（受取済・税引後）：前年同期比、累計、直近12か月、実績利回り、年平均成長率、未記入チェック、年推移、年または全期間を選んで月別受取額・銘柄別・口座別などを表示、月別の前年比較、銘柄別ランキング、普通分配・特別分配、口座別・種別の内訳
- 利回り：全銘柄の評価額合計から現在の利回り、取得額合計から取得利回りを表示
- 増配・減配：配当額の変更を「何年何月から」で登録。過去の見込み額や記入済みの配当は変わらない（記入時の税率も固定）
- バックアップの書き出し・読み込み（JSON）

データはiPhoneのSafari内（localStorage）に保存されます。初回はダミーデータが入っています（設定 →「すべてのデータを削除」で空にできます）。

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリを作る（例：`haitou-app`）
2. このフォルダのファイルをすべてアップロード（Add file → Upload files）
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/haitou-app/` で開けます
5. iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」

## 更新するとき
`index.html` を差し替えたら、`sw.js` の `VERSION` を `haitou-v2` のように上げると、iPhone側でも新しい版に切り替わります。

## 注意
- リポジトリを公開（Public）にしても、入力したデータは各自のiPhone内にしか保存されません。
- Safariの履歴・Webサイトデータを消すとデータも消えるので、設定画面から定期的に書き出してください。
